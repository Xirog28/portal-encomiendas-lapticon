# Portal de Encomiendas Lapticon

## Descripción
Aplicación web frontend para la gestión de encomiendas, integrada con un backend mediante una API REST y autenticación con Firebase.

## Tecnologías
- HTML5
- CSS3
- JavaScript
- Firebase Authentication
- API REST

## Funcionalidades
- Inicio de sesión.
- Consulta de ciudades disponibles.
- Creación de encomiendas.
- Consulta y listado de encomiendas.
- Gestión del estado de las encomiendas.

## Estructura del proyecto
- `Index.html`: estructura de la interfaz.
- `style.css`: estilos visuales.
- `script.js`: lógica del frontend e integración con el backend.
- `evidencias/`: capturas de las pruebas realizadas.

## Ejecución
Abre `Index.html` en un navegador o utiliza la extensión Live Server de Visual Studio Code.
